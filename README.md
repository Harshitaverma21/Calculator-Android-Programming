# Basic Calculator Android App

## 📌 Project Overview

This project is a **Basic Calculator Android Application** developed as part of the **BCA 4th Semester Android Programming course** at **Dezyne Ecole College, Ajmer**.
The application performs basic arithmetic calculations and helps in understanding the fundamentals of Android application development.

The main objective of this project is to learn how to design a simple Android user interface and implement basic logic for performing calculations.

## 🎯 Features

* Simple and user-friendly interface
* Performs basic arithmetic operations:

  * Addition (+)
  * Subtraction (−)
  * Multiplication (×)
  * Division (÷)
* Instant calculation results
* Lightweight and easy to use

## 🛠 Technologies Used

* **Programming Language:** Java / Kotlin
* **IDE:** Android Studio
* **Platform:** Android
* **User Interface:** XML Layouts

## 📂 Project Structure

The project mainly includes the following components:

* **MainActivity:** Handles the calculator logic and user interactions
* **Activity Layout (XML):** Designs the calculator interface
* **Resources Folder:** Contains strings, icons, and other supporting files

## ▶ How to Run the Project

1. Clone or download this repository.
2. Open the project in **Android Studio**.
3. Allow **Gradle** to sync the required dependencies.
4. Connect an Android device or start an emulator.
5. Click the **Run** button to install and launch the application.
